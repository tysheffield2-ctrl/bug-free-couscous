# ENCORE 0.8.2-beta.1 — Polish, Immersion & Living Industry

## Release goal

0.8.2 is intentionally not another large feature dump. It focuses on making ENCORE feel more coherent, readable and alive: faster song creation, stronger information hierarchy, richer NPC careers and a more premium interface treatment while preserving the 0.8/0.8.1 business, wealth, label, touring and investment systems.

## Delivered

### Faster studio flow
- Removed the Creative Brief control from song creation.
- Removed its hidden quality/appeal bonus from new songs.
- New songs now begin with a neutral session plan.
- Creative tradeoffs happen where they are easier to understand: recording and mixing session choices.
- Existing finished songs are not rewritten.
- An in-progress pre-recording draft that still contains a legacy Creative Brief is migrated to neutral session values so the removed mechanic does not continue influencing a new recording invisibly.
- Updated Guide and gameplay-tour copy so neither teaches the removed Creative Brief.

### Home information hierarchy
- Added a new `RIGHT NOW` executive brief near the top of Home.
- It surfaces up to four relevant decisions from:
  - open label/commercial/creative opportunities
  - unread Career Inbox items
  - unfinished studio projects
  - active or paused world tours
  - low energy when recovery remains available
- Every item routes directly to the relevant screen.
- When nothing is urgent, the brief explicitly tells the player they are clear to create instead of filling the page with warnings.

### Living NPC careers
- Added lightweight persistent career state for the core simulated artist population without eagerly bloating thousands of directory-only artists.
- Core NPCs now track:
  - momentum
  - career phase
  - current era/chapter
  - recent career event
  - career-peak audience
  - hiatus timing
- Career phases include Prime, Ascending, Steady, Rebuild, Quiet Era, Hiatus and Comeback.
- NPC momentum responds to release reception, release recency and monthly variance.
- Active NPC skill and reputation can move over time instead of remaining permanently frozen.
- Simulated career events can include:
  - breakout runs
  - quieter/slump periods
  - short hiatuses
  - reinventions/new eras
  - collaboration buzz
  - comebacks
- Events can move next-release timing and audience/reputation rather than existing only as flavor text.

### World Pulse
- Added a `World pulse` tab inside Industry.
- Shows leading current-momentum artists with stylized portraits, phase and era.
- Adds an industry-headline feed generated by simulated NPC career events.
- Headlines link back to the relevant artist profile.
- The existing Charts, Artists and New Releases pages remain intact.

### Richer artist profiles
- Existing relationship, feature, project and wealth information is preserved.
- Artist profiles now add a `CAREER PULSE` section showing:
  - current phase
  - named era/chapter
  - momentum score and direction
  - career-peak audience
  - recent career event
  - current/next project
  - projected release timing
- The goal is to make other artists feel like careers the player can follow rather than static collaboration menus.

### Premium interface pass
- Added a layered executive-brief surface with subtle accent glow, stronger information grouping and direct decision cards.
- Added richer World Pulse artist cards and headline rows.
- Added a dedicated career-pulse treatment inside artist profiles.
- Added restrained hover elevation/border response to high-traffic cards, artists, catalog listings and asset tiles.
- Tightened heading and large-number typography.
- Added responsive rules for phone-width layouts.
- No gameplay information was flattened into decorative images; all controls remain real HTML.

## Save and performance strategy

- 0.8.2 state is stored under `s.v082`.
- Persistent living-career state is limited to the active core artist population. Directory-only artists use derived state unless they belong to the active simulation, avoiding a major save-size increase across 2,500+ directory entries.
- Existing 0.8.1 careers migrate forward without reset.
- Previous releases, investments, contracts and historical recording values are preserved.

## Automated validation

`npm test` builds the game and runs the full existing regression suite plus `tests/v082.mjs`.

0.8.2-specific coverage checks:
- version is `0.8.2-beta.1`
- studio no longer renders `Creative brief`
- new songs receive neutral session quality/appeal values
- legacy in-progress pre-recording brief state migrates to neutral
- Guide copy no longer references Creative Brief
- Home renders the new executive brief
- active NPC career state persists
- forced NPC event generation produces industry headlines
- World Pulse renders successfully
- artist profiles render Career Pulse
- monthly NPC settlement keeps skills in valid bounds
- save validation continues to accept migrated careers

The first branch run correctly failed because an older studio regression still expected the removed Anthem Creative Brief's +4 appeal. That assertion was updated to expect only the recording/mixing bonuses. A later run correctly failed because older version assertions still expected 0.8.1; those were updated. The release-candidate branch then passed the complete suite.

## Current game-shape audit

### Strongest areas
- ENCORE now has a credible connected career loop rather than isolated feature screens.
- Music creation, audience growth, relationships, contracts, label ownership, touring, commercial deals, investments and legacy increasingly affect one another.
- 0.8.2 improves readability at the exact point where system count was becoming a liability.
- Other artists now have visible state and movement, which improves the sense of sharing a music industry rather than playing against static tables.

### Remaining beta priorities
1. **Physical mobile QA:** automated DOM/string tests still do not replace actual iPhone Safari testing for keyboard overlap, touch targets, long modals, browser-back gestures and animation smoothness.
2. **NPC consequence depth:** current career arcs affect momentum, audience, timing and headlines, but future work can connect them further into award odds, label disputes, catalog valuations, touring, friendships/rivalries and genre/cultural shifts.
3. **Information hierarchy:** Home is improved, but a long career can still accumulate many business systems. Future screens should prefer summaries and progressive disclosure over adding more permanent navigation tabs.
4. **Economy balancing:** $0.50 streams, mega tours, catalog investing, sports ownership and icon commercial deals intentionally allow enormous wealth. The next balance pass should preserve uncapped success while making billion-dollar outcomes rare and earned rather than automatic.
5. **Architecture consolidation:** compatibility modules are protecting old saves effectively, but before 1.0 the game should consolidate major state transitions/UI routing so future changes require fewer override layers.
6. **World continuity:** future NPC work can add longer memory—career-long rivalries, label loyalty, public friendships, repeated collaborator chemistry, retirement/return decisions and multi-era narratives.

## Playability assessment

0.8.2 remains a beta, but it is now much closer to a coherent music-industry sandbox than a prototype. The game can support long-running careers with music creation, social growth, labels, roster management, touring, commerce, wealth, catalogs, market investing, sports ownership, awards and world simulation while maintaining automated save/regression coverage.

The main remaining risk is no longer lack of features. It is presentation density, long-career balance and physical-device usability. That is a healthier problem to have approaching 1.0.
