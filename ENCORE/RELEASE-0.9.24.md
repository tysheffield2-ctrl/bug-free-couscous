# ENCORE 0.9.24-beta.1 — Living Memory Foundation

- Adds durable entity memory on top of Cohesion Core so important artist, agreement, case, track and player events survive the rolling activity feed.
- Adds explicit causal links between decisions and downstream events, including roster-request refusals into legal escalation and industry surges into chart consequences.
- Adds remembered artist relationship context across affinity, respect, rivalry and grievance instead of relying only on a flat relationship score.
- Connects remembered relationship history to collaborator negotiation terms while preserving legacy relationship storage for compatibility.
- Adds persistent memory panels to artist profiles and a defining Career Memory section to Artist File.
- Preserves high-salience career history with bounded memory storage and long-career pruning rules.
- Adds regression coverage for entity indexing, causal chains, relationship consequences, collaboration integration and high-salience retention.
