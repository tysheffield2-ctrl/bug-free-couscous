# ENCORE 0.9.28-beta.1 — Cohesive Career UI

- Rebuilds New Song into the approved mobile-first creation layout with large title input, album assignment, artist/writer/studio selectors, genre/clean controls, total cost and one clear Create action.
- Adds a dedicated Genre screen with current genre, left/right cycling and a 25-energy save cost when the career genre changes.
- Adds a ranked Featured Artists picker with Virality, Name, Rating and real ENCORE feature fees; existing booking rules remain authoritative.
- Recasts owned-label management into one coherent record-company presentation with Overview, Artists, Artist ROI and signed-artist detail views.
- Label ROI uses actual advances/receipts instead of fabricated financial values.
- Signed-artist detail uses the real NPC catalog, contract term, receipts, fans and career attributes.
- Hard-forces Artist File to a true white background with black writing so older dark-shell styles cannot create contrast problems.
- Keeps all song, feature, contract, royalty, label and long-career simulation logic unchanged under the new presentation.
