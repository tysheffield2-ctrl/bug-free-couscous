# ENCORE — Audience & Streaming Engine

## Audit score
**7.4/10**

## Current state
Audience changes increasingly pass through a shared mutation contract, and regional audiences are reconciled to the global true-fan total. Streaming has listener acquisition/churn, release lifecycle effects, regional attribution, marketing/social/tour inputs and long-career damping.

## Canonical goal
One explainable Audience Engine for every source of discovery and retention:

**Exposure → listener → follower → casual fan → true fan → loyal fan → churn/reactivation**

Every event should know its source and, when relevant, its market.

## Highest-priority backlog
- Deduplicate listeners/exposure across PULSE, streaming, tours, features, marketing and media.
- Calibrate conversion/churn across career tiers and long saves.
- Make saturation and repeat exposure visible/meaningful.
- Preserve exact regional/global reconciliation.
- Add source-attribution summaries so the player understands where growth came from.
- Connect fan loyalty/segments to ticket demand, merch, catalog behavior and release reception.
- Build exploit tests for repeated campaigns/posts/tours.

## Protected decisions
Regional fans are an attribution/decomposition of global true fans, not a second independent population.

## Do not drift
No gameplay system should directly add fans with its own private formula if the Audience Engine can represent the event.
