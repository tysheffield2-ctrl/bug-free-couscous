# ENCORE — Labels / Contracts / Negotiations

## Audit score
**8.3/10**

## Current state
ENCORE has distinct recording, distribution, publishing and 360 structures with explicit rights. Deals can include master/distribution/publishing/touring/merch/endorsement/media/sync participation, with required and excluded clauses by structure. Offers, countering, switching/buyouts, catalog participation and label ownership already create real strategy.

## Canonical goal
Contracts behave like long-term strategic relationships with obligations, leverage, performance expectations and consequences—not only a set of percentages.

## Highest-priority backlog
- Add release commitments, options, deadlines and performance clauses.
- Deepen recoupment/advance accounting and catalog/master consequences.
- Add renegotiation, disputes, breach/buyout scenarios and relationship consequences.
- Make label AI react to artist heat, genre strategy, roster conflicts and budget.
- Deepen A&R/executive relationships and competing-offer leverage.
- Improve 360 scopes and non-recorded income participation.
- Make player-owned label strategy/roster management an earned executive game.

## Protected decisions
- Contract rights remain explicit and visible before signing.
- Distribution deals preserve artist master ownership.
- New-career label ownership remains gated as an earned progression system; existing owners remain grandfathered.

## Do not drift
Do not hide consequential rights inside generic “royalty split” text. Every important participation clause should remain inspectable.
