# ENCORE — Awards / Legacy / Career Memory

## Audit score
**6.9/10**

## Current state
ENCORE already tracks Honors, certifications, achievements, milestones, chart history, career firsts, tour records and briefings. These pieces preserve events, but they do not yet form one coherent understanding of the artist’s career story.

## Canonical goal
**ENCORE remembers.** The game recognizes connected eras, rivalries, major contracts, tours, cities, slumps, comebacks, award seasons and cultural moments and presents them as durable career history.

## Highest-priority backlog
- Create named career eras/chapters from actual events rather than another manual log.
- Unify major milestones/history sources into one durable career-memory model.
- Rehaul awards judging around year-specific work, reception, cultural impact, touring, momentum and longevity.
- Make award ceremonies/events feel like annual narrative climaxes.
- Track rivalries/collaborations and repeated history across years.
- Preserve legacy after AI artists retire or leave the active world.
- Add Hall-of-Fame/legacy summaries only after the memory model is trustworthy.

## Protected decisions
Certifications, chart history and financial/tour records remain factual records even if narrative interpretation changes later.

## Do not drift
Do not create another independent “history” array for each new feature. Important events should feed one career-memory contract.
