# ENCORE — UI / UX & Navigation

## Audit score
**8.0/10 player-facing UI** · **6.7/10 real-device confidence**

## Current state
Recent passes materially improved Home, Artist File, Stats, Studio wheels and the graphical U.S. audience map. ENCORE now has a recognizable visual identity instead of a generic web-sim shell. The unevenness is between newly rebuilt screens and older destinations, plus navigation fragmentation caused by the game’s breadth.

## Canonical goal
A premium mobile-first music-career interface where every system feels like part of the same game while retaining a distinct visual identity. Bottom navigation stays small; Menu remains the directory; deep systems are grouped under meaningful hubs.

## Highest-priority backlog
- Consolidate all business-facing destinations under Business HQ at the presentation/navigation level.
- Audit every primary flow at iPhone width: creation, Home, Studio, Stats, Charts, PULSE, Touring, offers, map, Business HQ, saves and recap.
- Upgrade remaining legacy card-stack screens to the same visual standard as Artist File/map/Home.
- Standardize charts/graphs with richer graphical presentation and readable trends.
- Keep a universal Back action and predictable screen hierarchy.
- Remove stale month-era/help copy and ensure the walkthrough reflects current mechanics.
- Improve notifications/deep links for important offers: features, collaborations, production requests and tour invitations.

## Dependencies
Business HQ, Charts, PULSE, Touring, Studio and Awards each own their mechanics; this workstream owns presentation, navigation and cross-screen consistency.

## Do not drift
Do not redesign mechanics here. UI changes should expose the canonical system more clearly rather than create duplicate logic in presentation files.
