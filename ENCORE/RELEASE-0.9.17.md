# ENCORE 0.9.17-beta.4 — Release Strategy / Studio Flow

- Song creation now moves directly from writing to recording to mixing; the extra recording/mix session-choice menus have been removed while the creative brief, production budget, skills, features and song identity systems remain intact.
- Finished singles can now be scheduled up to 12 weeks ahead instead of being forced into the current week.
- A dedicated Release Strategy screen forecasts the next eight weeks using known release timing, artist scale, reputation, label backing and current industry pressure.
- Forecasts expose an intelligence-confidence score influenced by the player’s representation team; they are guidance, not guarantees, because Living Industry shocks can still change the week.
- Players can choose a protected lane, balanced rollout or deliberate head-to-head challenge for each scheduled single.
- Release timing now feeds the authoritative debut-stream engine through a bounded launch multiplier; preparation, competitive pressure, chosen posture and late schedule changes all matter.
- Head-to-head challenges can deepen rivalry history and reward a #1 or Top 10 debut with reputation, while a miss is preserved in release history.
- Rescheduling does not charge a second release fee, but moving a release inside the final week creates a persistent launch penalty.
- Pulling a release inside the final week costs reputation, so dates are commitments rather than cosmetic labels.
- Scheduled releases activate automatically before authoritative weekly stream settlement, preventing future-dated tracks from earning streams early.
- Album releases supersede scheduled single dates cleanly when an unreleased scheduled master is included on the album.
