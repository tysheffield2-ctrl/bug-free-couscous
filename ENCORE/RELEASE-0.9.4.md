# ENCORE 0.9.4 Beta 1

- Rebuilt Artist File into a cohesive premium dossier with one visual hierarchy instead of a long stack of competing cards.
- Added a current-chapter dashboard, music/release rail, regional/world signals, legacy board, and direct links to Stats, Audience, PULSE, Touring, Certifications, and career history.
- Added release hype for songs before release, including finished drafts and songs on the release shelf.
- Added pre-release album planning so an upcoming album can build hype before it enters the catalog; matching the planned title transfers that buildup into launch week.
- Added post-release hype actions for both songs and albums so players can extend momentum, revive catalog discovery, and keep an era active.
- Hype runs from 0 to 100, supports a true MAX HYPE state, is limited to three moves per release per week, decays over time, and feeds into weekly stream outcomes without guaranteeing a hit.
- Added sandbox-only PULSE follower editing.
- Added sandbox-only PULSE engagement-rate editing from 0% to 10,000%; normal careers never expose either control.
- Sandbox engagement overrides feed the displayed PULSE analytics and label-interest signal while preserving normal-career simulation rules.
- Preserved existing saves by adding the new hype and Artist File state through migration-safe fields.

Validation: production build, full regression suite, and targeted 0.9.4 checks for pre/post release hype, album planning, sandbox-only PULSE controls, and the Artist File redesign.
