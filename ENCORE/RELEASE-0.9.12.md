# ENCORE 0.9.12

- Restored separate artist profiles through Music Platform Ecosystem 1.0 instead of presenting every stream as one generic audience number.
- Added four distinct fictional audio services: VYBE for playlist/algorithm discovery, MUSE for album/library behavior, AMP for community and early discovery, and WORLDWAVE for global/radio reach.
- Split each song’s existing authoritative ENCORE weekly streams across those services without duplicating streams or royalties.
- Added service-specific monthly listeners, followers, saves, library adds, reposts, radio spins, editorial activity, playlist reach, top tracks and placement history.
- Connected PULSE song-linked attention to platform discovery so social activity can influence where a record catches on without directly inventing streams.
- Added organic platform placements including VYBE rotation, MUSE editorial support, AMP community repost networks and WORLDWAVE global rotation; strong placement can create bounded future catalog lift.
- Added FRAME, a dedicated video platform with visualizers, performance videos, official music videos and cinematic videos using real cash, energy, production budgets, subscribers, views and creator revenue.
- FRAME viewing can create a bounded next-week discovery spillover for the linked song, allowing visuals to revive or extend catalog momentum.
- Video creator revenue now enters the existing finance/tax system as attributed media income, while video production is recorded as a career expense.
- Added migration support that estimates platform history from an existing career’s catalog totals without rewriting prior royalties or inventing historical weekly events.
- Added Music Platforms to navigation with responsive mobile layouts and separate profile views for every service.
