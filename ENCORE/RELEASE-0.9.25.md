# ENCORE 0.9.25-beta.1 — Native Shell 3.0

- Rebuilds the main Home, Career/Music and Wealth hubs around the approved compact mobile layout while retaining ENCORE's own visual identity.
- Replaces reference-game placeholder actions with contextual ENCORE actions: catalog value opens **View Catalog**, earnings opens **View Finances**, and catalog-rights valuation opens the real Contracts & Rights hub.
- Adds a five-destination bottom navigation for Home, Artist File, Career, Wealth and More, with every tab wired to a live ENCORE destination.
- Makes Home a listener-and-career command center using real fame tier, career state, platform listener data, Inbox, relationships, PULSE, charts and the player's actual company/Business HQ.
- Makes Career a real music hub using lifetime streams, top songs, top albums, Studio, releases, artists/collaborations, contracts/rights, marketing, Touring, awards, platforms and commerce.
- Makes Wealth use ENCORE's actual cash, physical assets, simulated investments, music-catalog valuation, acquired catalog interests, finance ledger, property system and Business HQ.
- Keeps Energy in the persistent command bar instead of using it as an unrelated contextual button.
- Adds responsive mobile styling and regression coverage that rejects placeholder labels such as **Find a Job** or **Songboard** from these new hubs.
- Establishes a UI contract for future screens: nearby buttons must describe the ENCORE system or data they act on rather than borrowing unrelated labels for visual symmetry.
