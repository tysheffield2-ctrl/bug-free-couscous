# ENCORE 0.9.26-beta.1 — Editorial Artist File

- Rebuilds the player Artist File into the approved full-screen editorial profile layout with a black ENCORE masthead, PROFILE identity row, oversized artist name, real-time net worth block and long-form personal stat table.
- Keeps the screen ENCORE-native: no reference-brand wording or borrowed game labels are shipped.
- Feeds the profile from real career state including net worth, catalog value, streams, chart history, #1 records, touring gross and tickets, merch activity, awards, features, company ownership, fans, legacy score and career length.
- Uses real ENCORE substitutes when the game does not yet simulate a reference-screen field instead of inventing unsupported data.
- Preserves access to Stats 2.0, appearance editing, career history, awards/plaques and contracts/rights from the editorial file.
- Makes Artist File immersive on mobile by suppressing the surrounding app chrome while the profile is open; the profile close control returns to Home.
- Keeps the redesign in the split presentation shell so the core simulation bundle remains unchanged and within the existing deployment budget.
